How it works

Three clicks.
Keyboard silenced.

Lockey sits quietly in your menu bar and intercepts keyboard events at the system level when you need it.

1

Click the menu bar icon

Lockey lives in your macOS menu bar, always one click away — no extra windows or docks needed.

2

Lock your keyboard

Hit "Lock Keyboard" and Lockey immediately begins suppressing all standard key events at the system level.

3

Clean freely, unlock when done

Wipe down your keys without worry. Click "Unlock" in the menu to restore full keyboard functionality instantly.

Features

Built for the task.
Nothing more.

A focused utility that does one thing exceptionally well — keeping your keyboard silent while you clean it.

🖥

Menu Bar Only

No dock icon, no extra windows. Lockey lives exactly where it belongs — in your macOS menu bar, always accessible.

⚡️

Instant Lock & Unlock

One click to lock, one click to unlock. Keyboard interception activates and deactivates at the system level immediately.

🔇

Full Key Suppression

Suppresses standard keyboard events including attempts to intercept media and function-row system keys like brightness and volume.

🛡

Accessibility Guidance

Built-in step-by-step guidance for granting the required Accessibility permission — no digging through System Settings needed.

🧪

Tested Core

Unit tests cover the state machine, permission handling, and keyboard interception behavior to keep reliability high.

📦

Open Source

Built with Swift and AppKit, fully open source under the MIT license. Inspect, fork, or contribute on GitHub.

Requirements

What you need.

System Requirements

  • macOS 14 (Sonoma) or later
  • Accessibility permission enabled for Lockey
  • System Settings → Privacy & Security → Accessibility

Known Limitations

  • Touch ID & power button are hardware-controlled by macOS and cannot be intercepted
  • Some protected system contexts may restrict full event interception
